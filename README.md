Logistics based software to monitor and track within secure way.

# Freight Security Threat Model
A practical threat model for small carriers, freight brokers and logistics
companies that have no dedicated security team.

## Who this is for
- Small trucking and carrier companies
- Freight brokers and dispatch operations
- Logistics firms without an in-house security team

## What's inside
- `threat-model.md`: the threat model: assets, threats and mitigations
- `threat-model-diagram.png`: the diagram showing system components and trust boundaries

## How to use it
Read the diagram first to see where your own systems fit, then work through
the threats in order and apply the mitigations that match your setup.
